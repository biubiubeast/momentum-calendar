- `npm run test:integration` 通过：临时 SQLite + 真实 HTTP 服务验证登录、账号隔离、完整 JSON（含 2.1 项目、日程关联、成果和日周复盘）、旧页面拒绝覆盖、错误引用拒绝、修订冲突、来源/容量限制、重启持久化、退出失效。未使用生产数据。

## 回退

本次无需 SQL schema migration；新增字段保存在 JSON。优先前向修复。原版页面可能忽略未知字段，回退到 2.1 之前的应用后不得继续写入已升级记录，否则可能丢失成果/复盘。应用自动回滚不会自动回滚数据库；若确需旧版恢复，先导出当前完整 JSON、停止写入并设计兼容补丁。恢复旧数据库会丢失备份后新增记录，不作为常规更新步骤。
