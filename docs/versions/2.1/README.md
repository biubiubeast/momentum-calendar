# Momentum 2.1 开发记录

日期：2026-11-12（香港时间） · 应用版本：2.1.0 · 数据版本：2.1

本版本在公司 Ubuntu 版本上开发，继续使用 Next.js standalone、SQLite、独立账号与 `/Momentum` 路径。GitHub 是公司版本的源码来源；新账号的 Sites 站点使用同一界面和模型，通过单独适配层接入 ChatGPT 登录和 D1，两个站点不自动共享数据。

## 本次变化

- 产品与成果：长期任务的名称、说明、大类、多选标签、合作人、重要度、初始/结束日期；完成与重新开启；删除任务时保留日程，解除关联。
- 成果记录：进展、阶段成果、卡点；编辑/删除记录；卡点可解决或重新打开；突出最新未解决卡点。
- 日历关联：每天的时间块可关联未完成任务；保留已完成任务的历史关联；详情展示关联日程、每天投入、关键节点和进展。
- 筛选与排序：完成状态、大类、同时包含多个标签（AND）、关键词；创建时间、持续时间、进展时间、重要度双向排序；没有进展的任务始终排在进展排序末尾。
- 复盘：日历下方每日/每周复盘，手动保存，每篇最多 8000 字。每周记录使用周一为唯一日期；清空并保存可删除。
- 报表：选择周、月、年和该周期内任意日期，下载标准 `.xlsx`；8 张表包含概览、月/周/日汇总、日程进展、产品成果、成果卡点明细和复盘日记。空区间也能导出。
- 兼容：旧 JSON 无需迁移数据库；加载时补充空项目/复盘数组。写入包含数据版本；服务器拒绝旧页面覆盖已升级数据。
- 管理：建立每版本文档目录、模板和团队检查要求；提供单独 Sites 源码生成脚本。

## 明确边界

合作人当前是文本记录，不代表多人共享、邀请或权限。实际投入来自计时/补记，不根据完成百分比自动推算。完成长期任务不自动完成所有日程。任务持续时间按自然日计算，含首尾，不等于投入时长。报表按当前记录生成，尚不是不可修改的历史快照。通知仍需页面打开或导出到系统日历。交易计划未开发。
